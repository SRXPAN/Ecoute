 Повний огляд AI Interview Copilot                                                                                                              
                                                                                                                                                    
  Це реал-тайм асистент для співбесід, який слухає розмову, транскрибує її та генерує підказки на основі вашого резюме/контексту.                   
                                                                                                                                                    
  ---                                                                                                                                               
  🎯 Основний функціонал                                                                                                                            
                  
  1. Аудіо захоплення (AudioRecorder.py)

  - Мікрофон - записує вашу мову
  - Динаміки (Loopback) - записує голос інтерв'юера через системний аудіовихід
  - Використовує PyAudioWPatch для Windows WASAPI
  - Буферизує аудіо в черги для обробки

  2. Транскрипція (AudioTranscriber.py)

  Розумна система розпізнавання мови:

  Аудіо потік → VAD (Voice Activity Detection) → Groq Whisper API → Текст

  Ключові фічі:
  - ✅ Smart VAD - аналізує гучність (RMS > 100), ігнорує фоновий шум
  - ✅ Автоматична мова - розпізнає українську, англійську, польську без налаштувань
  - ✅ Phrase Timeout - відправляє фразу після 1 сек тиші
  - ✅ Max Duration - примусово відправляє після 7 сек (для довгих монологів)
  - ✅ Фільтр галюцинацій - видаляє типові помилки Whisper ("thank you", "you")
  - ✅ Deque буфер - зберігає лише останні 10 фраз (економія пам'яті)

  Процес:
  1. Аудіо чанк → Перевірка RMS (чи це голос?)
  2. Якщо голос → додати в буфер
  3. Якщо тиша 1 сек АБО говорить 7+ сек → відправити в Groq
  4. Groq Whisper → текст
  5. Текст → додати в transcript_data

  3. AI Підказки (LLMClient.py)

  Генерація підказок через Zhipu AI:

  Питання інтерв'юера → Zhipu GLM-4-plus → Стрімінг підказок

  Архітектура:
  System Prompt (контекст резюме)
      + History (останні 3 пари Q&A)
      + Нове питання
      → Zhipu API (streaming)
      → 3-4 bullet points

  Ключові фічі:
  - ✅ Sliding Window - історія обмежена 6 повідомленнями (3 питання + 3 відповіді)
  - ✅ Streaming - підказки з'являються слово за словом
  - ✅ Автомова - відповідає тією ж мовою, що й питання
  - ✅ Формат - короткі bullet points (5-10 слів), без пояснень

  Приклад:
  Інтерв'юер: "Tell me about a time you optimized performance"

  AI Copilot:
  • Reduced API latency 60% with caching
  • Implemented Redis for session storage
  • Optimized database queries with indexes
  • Result: handled 10x traffic spike

  4. Інтерфейси

  A. Launcher (launcher.py)

  Стартове вікно для налаштування:
  - 🎙️  Вибір мікрофона
  - 🔊 Вибір динаміків (loopback)
  - 🔑 API ключі (Groq + Zhipu)
  - 📄 Контекст (резюме/опис вакансії)
  - Зберігає все в .env та temp_context.txt

  B. Dashboard (main.py)

  Головне робоче вікно:

  Ліва панель (📝 Live Transcript):
  - Показує реал-тайм транскрипцію
  - Формат: You: [текст] та Speaker: [текст]
  - Останні 10 фраз
  - Кнопка "Clear Session" - очищає історію

  Права панель (💡 AI Copilot):
  - Стрімінг AI підказок
  - Оновлюється автоматично при новому питанні інтерв'юера
  - Кнопка "Toggle Stealth Overlay" - показує/ховає overlay

  C. Stealth Overlay (StealthOverlay.py)

  Плаваюче вікно для стелс-режиму:

  Унікальні фічі:
  - ✅ Screen Capture Exclusion - невидиме в Zoom/Teams/OBS
  - ✅ Frameless - без рамок Windows
  - ✅ Always on top - завжди поверх інших вікон
  - ✅ Draggable - можна перетягувати
  - ✅ Transparent color - прозорий фон
  - ✅ Мінімалістичний дизайн - тьмяні кольори, не привертає увагу

  Windows API магія:
  SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)
  # Вікно стає невидимим для захоплення екрану!

  Крок 3: Захист від детекції

  Race Condition Protection:
  - Глобальний прапорець is_generating
  - Блокує нові запити поки йде генерація
  - Запобігає подвійним викликам API

  Memory Leak Protection:
  - Sliding Window (6 повідомлень)
  - Deque з maxlen=10 для транскриптів
  - Автоматичне обрізання історії

  Stealth Mode:
  - Screen capture exclusion (Windows API)
  - Прозорий фон
  - Мінімалістичний дизайн
  - Невидимий в Zoom/Teams

  🔒 Безпека та обмеження

  Що програма НЕ робить:

  - ❌ Не записує аудіо на диск
  - ❌ Не зберігає історію після закриття
  - ❌ Не відправляє дані нікуди крім Groq/Zhipu API
  - ❌ Не автоматично відповідає за вас

  Обмеження:

  - Потребує стабільний інтернет (API виклики)
  - Працює тільки на Windows (WASAPI)
  - Groq API має ліміти (безкоштовний план)
  - Zhipu API потребує китайський номер телефону для реєстрації
