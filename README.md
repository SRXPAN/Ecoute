# 🚀 Ecoute: Professional AI Copilot

**Ecoute** — це десктопний AI-асистент реального часу, створений для допомоги на технічних співбесідах та під час робочих дзвінків з іноземними клієнтами. 

Програма слухає аудіо з мікрофона та динаміків (Zoom, Teams, Google Meet), транскрибує розмову "на льоту" та миттєво генерує професійні підказки на екрані.

---

## 🔥 Кілер-фічі (Ключовий функціонал)

*   👻 **Stealth Mode (Невидимість):** Завдяки інтеграції на рівні Windows API (Rust), вікно програми **повністю невидиме** при демонстрації екрана (Screen Sharing) у будь-якій програмі.
*   🧠 **Два професійні режими (Personas):**
    *   💼 *Interview Copilot:* Експертні, розгорнуті відповіді для проходження технічних та HR-співбесід.
    *   🌍 *Client English Assistant:* Синхронний переклад того, що хоче клієнт, та генерація професійної відповіді англійською мовою (формат: Суть -> Текст для озвучки).
*   📄 **Розумний контекст (Job Matcher):** ШІ генерує відповіді не з пустих слів. Ви можете завантажити своє **PDF-резюме** та вставити **URL вакансії/таски** (вбудований парсер автоматично витягне текст із сайту).
*   ⏳ **Speech Rate Monitor (Контроль темпу):** Якщо ви почнете хвилюватися і говорити занадто швидко (понад 160 слів за хвилину), програма виведе попередження *"⏳ Speak Slower!"*.
*   ❄️ **Режим Freeze:** Можливість "заморозити" екран, щоб спокійно дочитати підказку, поки рекрутер продовжує говорити (аудіо при цьому продовжує записуватися у фоні).
*   📊 **Історія та Аналітика:** Усі сесії автоматично зберігаються. Вкладка History дозволяє переглянути транскрипт минулого дзвінка, проаналізувати співвідношення часу розмови (Talk Ratio) та експортувати лог у **Markdown** для Notion чи Obsidian.

## 🛠 Технічний стек

Проект побудований за сучасною мікросервісною Sidecar-архітектурою:

*   **Frontend (UI/UX):** React, TypeScript, Tailwind CSS v4.
*   **Desktop App Engine:** Tauri v2 (Rust) — для компіляції легкого `.exe`, доступу до ОС (Stealth Mode) та управління життєвим циклом бекенду.
*   **Backend:** Python 3, FastAPI, WebSockets.
*   **Audio Capture:** `pyaudiowpatch` (захоплення WASAPI Loopback для динаміків).
*   **AI / LLM:** 
    *   *Speech-to-Text:* Whisper API (via Groq) для надшвидкої транскрипції.
    *   *Inference:* Локальні LLM через LM Studio для абсолютної приватності та швидкості.
