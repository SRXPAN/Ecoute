🎯 AI Interview Copilot
AI Interview Copilot — це готовий до використання ШІ-помічник для співбесід з унікальним режимом невидимки (Stealth Mode). Він допомагає успішно проходити технічні інтерв'ю, надаючи контекстні підказки в реальному часі, які залишаються абсолютно непомітними для інтерв'юерів, навіть якщо ти поширюєш свій екран.

🌟 Головні можливості
✅ Надшвидка транскрипція — Groq Whisper API (затримка 200-500 мс).

✅ ШІ-підказки — Google Gemini, що генерує короткі тези на основі твого резюме.

✅ Stealth Mode (Оверлей-невидимка) — вікно, яке не бачать програми для запису чи трансляції екрана (Zoom, Teams, Meet).

✅ Мультимовність — автоматично розпізнає мову співрозмовника і відповідає тією ж мовою.

✅ Запуск в 1 клік — зручний графічний лаунчер для вибору мікрофона та введення налаштувань.

🚀 Швидкий старт (За 5 хвилин)
Крок 1: Отримання безкоштовних API ключів
Для роботи потрібні два ключі:

Groq API (для розпізнавання голосу): Зареєструйся на console.groq.com, створи API Key та скопіюй його.

Gemini API (для генерації підказок): Зайди на aistudio.google.com/app/apikey і створи свій ключ.

Крок 2: Встановлення
Переконайся, що у тебе встановлено Python 3.8+.

Bash
# Клонуємо репозиторій
git clone <repo-url>
cd ecoute-main

# Встановлюємо залежності
pip install -r requirements.txt
Крок 3: Запуск і конфігурація
Запусти програму за допомогою скрипта start.bat або командою python launcher.py. Відкриється вікно налаштувань (Launcher):

Обери свій мікрофон та динаміки зі списку (програма сканує їх автоматично).

Встав свої ключі Groq та Gemini (вони збережуться у файлі .env, тому вводити їх треба лише один раз).

У велике текстове поле встав своє резюме та опис вакансії (Context).

Натисни START.

🕵️ Режим невидимки (Stealth Mode Overlay)
Це головна зброя проєкту. Оверлей — це напівпрозоре чорне вікно без рамок, яке завжди знаходиться поверх інших вікон. У ньому з'являються короткі тези-підказки.

Як це працює?
Програма використовує Windows API (SetWindowDisplayAffinity з прапорцем WDA_EXCLUDEFROMCAPTURE). Це робить вікно повністю виключеним із захоплення екрана.

Що бачиш ти: Напівпрозоре віконце із зеленим текстом підказок, яке можна тягати мишкою.

Що бачить інтерв'юер (при скріншерінгу): Чорний прямокутник або просто фон твого робочого столу без жодного тексту.

Протестовано на: Zoom, Microsoft Teams, Google Meet, OBS Studio.

🧠 Як працює ШІ (Промпт)
ШІ навчений генерувати підказки виключно у форматі 3-4 коротких тез (bullet points).
Він ніколи не пише довгих речень, щоб ти не виглядав так, ніби читаєш із суфлера. ШІ використовує ключові слова з твого контексту (резюме) та автоматично відповідає тією ж мовою, якою було поставлене запитання (англійська, українська, польська тощо).

💡 Поради щодо використання
Під час співбесіди:
Розташування: Постав стелс-вікно якомога ближче до веб-камери, щоб зберігати зоровий контакт.

Не читай дослівно: Використовуй тези ШІ лише як тригери для пам'яті. Розгортай думку своїми словами.

Природні паузи: Коли чуєш складне питання, зроби природну паузу ("Гарне питання, дайте секунду подумати"), щоб дати ШІ 1-2 секунди на генерацію підказки.

🐛 Вирішення проблем (Troubleshooting)
Помилка аудіо (Error -99997 Invalid sample rate): Виникає, якщо пристрій не підтримує задану частоту. (Переконайтеся, що ви використовуєте останню версію коду, де частота визначається автоматично).

Стелс-вікно видно на трансляції: Ця функція вимагає ОС Windows 10 (версія 2004 і новіше) або Windows 11. На старіших системах або macOS/Linux API не спрацює.

Немає транскрипції: Перевір валідність Groq API ключа у файлі .env та переконайся, що обрано правильний мікрофон/динаміки в лаунчері.
